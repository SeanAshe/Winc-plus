winc keeps its settings, recently opened folders and backups of unsaved changes in this
folder instead of your user profile. Delete this folder to keep them in the user profile
(%APPDATA%\winc and %LOCALAPPDATA%\winc).

winc 将设置、最近打开的目录和未保存内容的备份保存在此目录中，而不是用户目录中。删除此目录后，
这些内容保存在用户目录中（%APPDATA%\winc 和 %LOCALAPPDATA%\winc）。
